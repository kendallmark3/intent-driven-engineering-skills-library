# Skill Design Principles

## 1. Progressive disclosure

The Skill description is the discovery surface. `SKILL.md` contains the working procedure. Optional examples and deeper references remain separate so they are loaded only when useful.

## 2. Minimum sufficient constraint

A Skill should not turn a goal into a giant implementation plan unless deterministic sequencing is truly required.

## 3. Evidence-driven expansion

New requirements should emerge from observed gaps, not agent imagination.

## 4. Explicit stop conditions

Every iterative Skill needs a way to terminate successfully.

## 5. Small, composable capabilities

Prefer multiple focused Skills over one giant "engineering" Skill.

## 6. Trust boundary awareness

A Skill can influence tool use and code execution. Review Skill changes like code changes.
